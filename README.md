# 피아노 템포 트레이너

개인 연습용 도구: MusicXML 악보를 업로드하면 원하는 BPM으로, 피치 왜곡 없이
피아노 음색으로 재생하고, 메트로놈과 구간 반복 연습을 지원한다. 서버 없이
브라우저에서만 동작하는 PWA(설치형 웹앱)다.

## 사용 방법

이 폴더(`frontend/`) 전체를 정적 웹 호스팅(예: GitHub Pages)에 올리거나,
로컬에서 정적 파일 서버(예: `python -m http.server`, 또는 그와 동등한 도구)를
띄워서 `http://localhost:...` 또는 `http://<내부IP>:...` 로 접속하면 된다.

- `index.html`을 휴대폰 저장소에 복사해서 파일 탐색기로 더블클릭해 여는
  방식(`file://` 경로)은 동작하지 않는다. 서비스 워커는 `https://`나
  `http://localhost` 같은 보안 컨텍스트에서만 등록되고, 피아노 사운드폰트를
  불러오는 `fetch` 요청도 `file://` 오리진에서는 브라우저(특히 크롬)가
  막아버리기 때문이다. 반드시 위와 같이 실제 HTTP(S) 경로로 접속해야 한다.

접속 후 "홈 화면에 추가"(또는 "설치")를 하면 오프라인에서도 계속 쓸 수
있는 앱처럼 동작한다.

## 사용법

1. MusicXML(.musicxml/.mxl) 파일을 업로드 (업로드한 파일은 브라우저에
   캐시되어, 다음에 "이전 파일 이어서 열기"로 바로 다시 열 수 있음 — 모든
   브라우저/기기에서 동일하게 동작함)
2. ▶ 버튼으로 재생 시작 (모바일 브라우저는 자동재생이 막혀 있어 반드시
   직접 눌러야 함)
3. BPM 슬라이더로 속도 조절 (재생 중에도 즉시 반영됨, ⏪10초/10초⏩ 버튼으로
   현재 템포 기준 10초씩 앞뒤로 이동 가능)
4. 🎹 곡 음량 / 🔔 메트로놈 음량 슬라이더로 각각 따로 조절
5. 메트로놈 소리는 노이즈 틱 / 사인 비프 / 우드블록 중 선택 가능
6. 어려운 구간은 "구간 시작 지정" → "구간 끝 지정" → 🔁 반복 켜기로 반복 연습
7. 도돌이표(`|: :|`) 반복 구간은 자동으로 재생에 반영됨

## 테스트

```bash
node --test frontend/scheduler.test.js
node --test frontend/synth.integration.test.js
node --test frontend/midi-parser.test.js
node --test frontend/xml-score-reader.test.js
```

## 알려진 한계

- 반복(도돌이표) 구간이 있는 악보에서는, 페달 정보가 원본(반복 전) 악보
  기준 위치로 계산돼서 실제 반복된(펼쳐진) 재생 위치와 어긋날 수 있음 —
  첫 번째 반복 이후부터는 페달이 의도한 위치가 아닌 다른 음에 적용될 수
  있음 (반복 자체는 정상적으로 재생됨).
- iOS Safari는 오래 사용하지 않은 PWA의 캐시를 지울 수 있어서, 그런 경우
  다시 열 때 음원 파일(약 30MB)을 한 번 더 받아야 할 수 있음.
- 박자표가 곡 중간에 바뀌거나, 곡이 온전하지 않은 마디(피크업/여린내기)로
  시작하는 악보는 마디 경계 계산이 정확하지 않을 수 있음 (메트로놈/구간
  반복 기능에 영향).
- 안드로이드 Chrome에서는 앱 아이콘 이미지가 아직 없어서 "홈 화면에
  추가/설치" 안내가 안 뜰 수 있음 (아이폰 Safari는 영향 없음). 그래도
  주소로 접속해서 쓰는 데는 문제없음.
